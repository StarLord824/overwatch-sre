# Track 03: Build Your Own
_Observe anything with SigNoz_

## Example Builds

* **Observability for Bots, Game Servers, or IoT Fleets**
  * Observability for a Slack/Discord/Telegram bot, a game server, or an IoT fleet.
* **Monitor a Trading Bot or Data Pipeline**
  * Monitor a trading bot or a data pipeline end to end.
* **Monitor Anything Weird with a Live Dashboard**
* **Novel Integration**
  * For example: Bridge an unsupported data source into SigNoz.
* **Ecosystem Plugin**
  * For example: Backstage plugin, Terraform module, or Helm chart for self-host.
* **Alert-Powered Hardware**
  * For example: Alert on a slow 3D print and trigger a buzzer, a light, LED strip, or lava lamp on the desk wired to alert state.
